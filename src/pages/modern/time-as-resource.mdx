# Time as a Resource

Pecorella's `t` is an axis on the chart; in the modern genre it's something you spend,
buy, allocate, and race. Four pins:

- **Zero-sum time budgets** — the project's namesake. Groundhog Life's 1440 min/loop,
  Omsi Loops' 250 mana where mana = time, Cavernous II's action queues. Knapsack math:
  `Σ duration_i · count_i ≤ T_budget`, maximize reward.
- **Speed multipliers as effective time** — AD tickspeed, Progress Knight 2's 10,000×.
  `effective_time = ∫ speed(t) dt`, with the feedback wrinkle that speed itself is bought
  from production.
- **Action duration as mutable state** — Cavernous II / Omsi Loops:
  `actionDuration = baseDuration × specialMult × realmMult`, training reduces base.
  Order matters because earlier actions reshape later costs.
- **Time as decay/pressure** — Increlution's `health = 0.5 × 1.25^(seconds/60)` makes
  time the opponent. Optimization shifts to "maximize progress before death."
