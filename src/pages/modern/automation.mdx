# Automation

Pecorella's `1c–1e` Optimal Choice answers "which generator do I buy next?" statically.
Modern games turn that into a UI surface and a *policy*: AD's autobuyer priority sliders,
Synergism's auto-everything tiers, NGU's "buy max" toggles. Three canonical policies —
**buy-when-affordable**, **buy-max-each-tick**, **threshold-based** — produce different
production-curve shapes. Convergence question: does dynamic autobuy approach the
static-optimal answer, or systematically deviate?
