# Challenges

Challenge runs as a first-class modern mechanic. AD challenges (disable a layer, mutate
an exponent), Synergism corruptions (stackable debuff multipliers persisting across
ascensions), NGU challenges (re-runs under constraints), Realm Grinder R-challenges. The
design math: how do you build a "hard mode" that produces a **different curve shape**,
not just a slower one? Prestige cycles run the same loop bigger; challenges run
*different loops*.
